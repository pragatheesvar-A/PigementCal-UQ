# Claims, evidence and safe wording

"Can I claim it?" is YES only where a test or log in this repository backs it. Everything about real people, real devices or clinical use is NO.

## Wording sweep (this audit)
Searched UI strings, README, comments and docs for: accurate, clinical, medical-grade, fair, bias-free, correction, melanin, guaranteed, probability, validated, device-agnostic, real-time, real-world, saves lives.
- **Changed:** "Device-agnostic" badge → "Records the device used"; Summary research question no longer says "device-agnostic" (states cross-device generalization is not evaluated); "Real-time" badge/blurbs → "Live, about 1 s updates"; README / hardware README "real time" → live with update rate; Summary Novelty "subgroup-validated" → "proposed… no real-data validation has been performed yet" (earlier pass); footer "nothing is simulated" → "the application itself generates no data" (earlier pass); README first paragraph (it said the app "does not generate or simulate data" while describing the Virtual MAX30102).
- **Kept (technically supported, always negated or qualified):** every "not clinically validated", "not a probability", "not a per-cell guarantee", "95% CI" (participant-level bootstrap interval), quantile levels 5 %/95 %, "correction" in "finite-sample correction" / "conformal correction", "melanin" (never appears), "fair/fairness" only in "does not claim … fairness".
- **Not added:** the phrase "Research prototype" in the footer was NOT added, because the project owner earlier asked that this phrase appear nowhere; the footer keeps "Not a diagnostic device. Not clinically validated."

## Second-pass wording changes
- Live Monitor reliability heading now says it is the rule engine (no calibrated interval) and points to Reliability Check for the calibrated CQR/Mondrian assessment.
- README: "RED not reproduced" replaced by the intermediate-noise scenario statement above; provenance paragraph added.
- Gate labels: name markers alone no longer produce "SOFTWARE TEST DATA" (they give UNVERIFIED DATA and block); only hash-bound provenance classifies test data.
- Not introduced: device-agnostic, real-time clinical, validated, diagnostic, clinically accurate, skin-tone correction.
